# Potrero Sector Map Trainer (Zones 27A / 27B / 27C)

An interactive tactical landmark and route navigation trainer covering **Potrero, CA (CA-94 / Zones 27A, 27B, and 27C)**.

## Features
- **🧭 Study / Explore Mode:** Pan and zoom across Zones 27A (West), 27B (South), and 27C (NE). Click any landmark, trail marker (`1T–18T`), or major intersection to inspect its coordinates and tactical notes.
- **🎯 Landmark Locator Mode:** Test your spatial awareness by locating specific landmarks and trail markers directly on the map.
- **🛣️ Route Nav Mode:** Plot routes between origins and destinations across sector roads and trails.
- **⚡ Sector Blitz Mode:** Rapid-fire multiple-choice identification quiz with live score, streak, and accuracy tracking.

## Quick Start
Open `index.html` in any modern web browser, or visit the live GitHub Pages deployment link.
